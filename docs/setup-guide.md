# সেটআপ গাইড — প্রথমবার চালু করা

PKOS কোনো অ্যাকাউন্ট ছাড়াই পুরোপুরি ফোনে চলে। নিচের সংযোগগুলো **ঐচ্ছিক** এবং প্রতিটি আপনি নিজে চালু না করলে বন্ধ থাকে।
কোনো token বা key কখনো চ্যাট, কোড, GitHub বা ইমেইলে দেবেন না — শুধু অ্যাপের নির্দিষ্ট ঘরে লিখবেন
(Android Keystore দিয়ে এনক্রিপ্ট হয়ে শুধু ওই ফোনে থাকে, ব্যাকআপেও যায় না)।

| সুবিধা | ডিফল্ট | কোথায় |
|---|---|---|
| ক্লাউড AI (Gemini বা OpenAI-compatible) | বন্ধ | সেটিংস → AI সেটিংস |
| Notion সিঙ্ক | বন্ধ | সেটিংস → Notion সংযোগ |
| Google Drive এনক্রিপ্টেড ব্যাকআপ | বন্ধ | সেটিংস → ব্যাকআপ ও সিঙ্ক |
| বড় ফাইল Drive লিংক হিসেবে Notion-এ | বন্ধ | Notion সংযোগ পর্দা |
| লিংকের শিরোনাম/বিবরণ আনা | বন্ধ | সেটিংস → জ্ঞান-সরঞ্জাম |
| ভুলে যাওয়া জ্ঞান মনে করানো (নোটিফিকেশন) | বন্ধ | সেটিংস → জ্ঞান-সরঞ্জাম |
| ভাসমান সেভ বোতাম | বন্ধ | সেটিংস → সেভ করা |
| নতুন তথ্য শুধু ফোনে রাখুন | বন্ধ | সেটিংস → গোপনীয়তা |

## ১. প্রথম চালু
পরিচিতি পর্দাগুলো দেখুন (বা "এড়িয়ে যান")। সেটিংস → চেহারা থেকে থিম ও ভাষা (বাংলা/English) বেছে নিন।
যেকোনো অ্যাপ থেকে Share → **PKOS** দিলেই সেভ হয়ে যায় — কিছুই সেটআপ না করেও।

## ২. Notion (ঐচ্ছিক)
1. notion.so/profile/integrations → New integration → **Internal**; capability: Read, Update, Insert content।
2. Notion-এ *My knowledge Hub → Master Database* → ⋯ → Connections → integration-টি যোগ করুন।
3. PKOS → সেটিংস → **Notion সংযোগ** → token লিখুন → "সেভ ও যাচাই"। "সংযোগ কাজ করছে" দেখালে **স্বয়ংক্রিয় সিঙ্ক** চালু করুন।
4. PKOS Master Database-এর কোনো column বা option যোগ/বাদ/নাম-পরিবর্তন করে না; পুরোনো পেজে হাত দেয় না।
5. ৫ MB-এর বড় ফাইল (Notion ফ্রি সীমা): চাইলে "বড় ফাইল Google Drive লিংক হিসেবে" চালু করুন (আগে Drive সংযোগ লাগবে)।
   ফাইলটি আপনার Drive-এর "Personal Knowledge OS Files" ফোল্ডারে **এনক্রিপশন ছাড়া** থাকে; লিংক শুধু আপনার অ্যাকাউন্টে খোলে।

## ৩. Google Drive ব্যাকআপ (ঐচ্ছিক)
Google Cloud-এ একবার বিনামূল্যের OAuth সেটআপ লাগে — ধাপগুলো [backup-restore-guide.md](backup-restore-guide.md) এবং
release build-এর জন্য [release-signing-and-oauth.md](release-signing-and-oauth.md)।
তারপর: সেটিংস → **ব্যাকআপ ও সিঙ্ক** → Google Drive যুক্ত করুন → **রিকভারি কী** তৈরি করুন → কাগজে/পাসওয়ার্ড ম্যানেজারে লিখে রাখুন
→ শেষ ৪টি অক্ষর লিখে নিশ্চিত করুন → "এখনই ব্যাকআপ" বা দৈনিক স্বয়ংক্রিয় ব্যাকআপ।
**রিকভারি কী হারালে ব্যাকআপ কেউ খুলতে পারবে না — PKOS-ও না।**

## ৪. ক্লাউড AI (ঐচ্ছিক)
ছাড়াই অ্যাপ ফোনের নিয়ম দিয়ে সাজায়। চালু করলে শুধু শিরোনাম, সংক্ষিপ্ত লেখা, URL, প্ল্যাটফর্ম ও ক্যাটাগরির নাম যায়; ফাইল, নোট বা
"শুধু ফোনে" আইটেম কখনো যায় না। কার্ড নম্বর, OTP, পাসওয়ার্ড ইত্যাদি পেলে আইটেমটি নিজে থেকেই "শুধু ফোনে" হয়ে যায়।
- **Gemini**: aistudio.google.com থেকে নিজের বিনামূল্যের API key → AI সেটিংস → key লিখুন → ক্লাউড AI চালু।
  ফ্রি সীমা শেষ হলে অ্যাপ ফোনের নিয়মে ফিরে যায়; কোনো পেইড প্ল্যান চালু করে না।
- **OpenAI-compatible**: AI সেটিংস → "OpenAI-সামঞ্জস্যপূর্ণ" → https এন্ডপয়েন্ট, মডেলের নাম, (ঐচ্ছিক) key।
  **সতর্কতা: আপনার বেছে নেওয়া সার্ভিস টাকা কাটতে পারে** — খরচের নিয়ম আপনার অ্যাকাউন্টের। অর্থ-ভিত্তিক সার্চ তখন অফলাইন পদ্ধতিতে চলে।
- কী পাঠানো হলো দেখতে: সেটিংস → **গোপনীয়তা ও তথ্য** → ক্লাউড কার্যকলাপ।

## ৫. অন্যান্য
- **লিংক প্রিভিউ** চালু করলে শেয়ার করা লিংকের প্রকাশ্য শিরোনাম/বিবরণ আনা হয় — ওই ওয়েবসাইট অনুরোধটি দেখতে পায়।
- **ভাসমান বোতাম**: চালু করলে "অন্য অ্যাপের উপরে দেখানো" অনুমতি চাওয়া হয়; বন্ধ করলে বোতাম চলে যায়।
- **মনে করানো**: Android 13+-এ নোটিফিকেশন অনুমতি চাওয়া হয়।

# Recovery runbook — কিছু হারালে বা ভাঙলে কী করবেন

মূল নিয়ম: ফোনের ডাটা আগে; Drive বা Notion-এর কোনো ব্যর্থতা কখনো ফোনের ডাটা মোছে না।
তিনটি জিনিস আপনার নিজের দায়িত্বে নিরাপদ রাখুন: **রিকভারি কী**, **release keystore + পাসওয়ার্ড**, **Google অ্যাকাউন্ট**।

| # | পরিস্থিতি | করণীয় |
|---|---|---|
| 1 | ফোন হারিয়েছে / নতুন ফোন | নতুন ফোনে PKOS install → সেটিংস → ব্যাকআপ ও সিঙ্ক → একই Google অ্যাকাউন্টে Drive যুক্ত → "ব্যাকআপ বাছুন" → রিকভারি কী → প্রিভিউ দেখে "আমি বুঝেছি" → রিস্টোর। অ্যাপ নিজে restart হয়। তারপর Notion token ও AI key আবার লিখুন (এগুলো ব্যাকআপে থাকে না)। |
| 2 | অ্যাপ uninstall/reinstall | উপরের ১-এর মতোই। Notion-এ নতুন করে ডুপ্লিকেট পেজ তৈরি হয় না (Capture ID দিয়ে পুরোনো পেজ চেনে)। |
| 3 | রিস্টোর মাঝপথে বন্ধ/ব্যর্থ | রিস্টোরের আগে বর্তমান ডাটার নিরাপত্তা-কপি রাখা হয়; ব্যর্থ হলে সেটিই ফিরে আসে। নেট ঠিক করে আবার রিস্টোর চালান। |
| 4 | "চেকসাম মেলেনি" / ব্যাকআপ নষ্ট | ওই ব্যাকআপ গ্রহণ করা হয় না। তালিকা থেকে আগের কোনো ব্যাকআপ বাছুন। কোনো ফাইল ব্লব অনুপস্থিত হলেও রিস্টোর থামে — আধা-রিস্টোর হয় না। |
| 5 | রিকভারি কী হারিয়েছেন | পুরোনো ব্যাকআপ খোলা **অসম্ভব** (কেউ পারবে না)। ফোনে ডাটা থাকলে: সেটিংস → রিকভারি কী → নতুন কী তৈরি → সঙ্গে সঙ্গে নতুন ব্যাকআপ নিন। |
| 6 | Drive-এ জায়গা শেষ | ব্যাকআপ শুরুর আগেই সতর্ক করে, কিছু মোছে না। Drive খালি করুন বা ব্যাকআপ রাখার সংখ্যা কমান। |
| 7 | Google অনুমতি বাতিল / "সংযোগ দরকার" | ব্যাকআপ ও সিঙ্ক → আবার Drive যুক্ত করুন। `DEVELOPER_ERROR` হলে OAuth client-এর package ও SHA-1 মেলান ([গাইড](release-signing-and-oauth.md))। |
| 8 | Notion token বাতিল / integration সরানো | আইটেম "অনুমতি দরকার" অবস্থায় অপেক্ষা করে, ফোনে অক্ষত থাকে। Notion সংযোগে নতুন token → "সেভ ও যাচাই" → "এখন সিঙ্ক"। |
| 9 | Notion-এ দ্বন্দ্ব | আইটেমে "Notion রাখুন" বা "ফোনেরটা রাখুন" বাছুন — PKOS নিজে থেকে কারো লেখা মুছে দেয় না। |
| 10 | ভুল করে আইটেম মুছেছেন | Notion পেজ ও আগের ব্যাকআপে আছে। পুরো ব্যাকআপ রিস্টোর করলে **সব ডাটা ওই সময়ে ফিরে যায়** (পরের নতুন আইটেম হারাবে) — তাই আগে এক্সপোর্ট নিন, অথবা Notion থেকে লেখাটি কপি করে নতুন করে সেভ করুন। |
| 11 | অ্যাপ খুলছে না / বারবার বন্ধ | ফোন restart। না হলে একই key-এর নতুন build-এর ওপর install (ডাটা থাকে)। uninstall শেষ উপায় — তার আগে নিশ্চিত হন সাম্প্রতিক ব্যাকআপ আছে। |
| 12 | Release keystore হারিয়েছেন | একই অ্যাপের আপডেট আর বানানো যাবে না। নতুন key দিয়ে build → পুরোনো অ্যাপে শেষ ব্যাকআপ নিন → uninstall → নতুনটি install → রিস্টোর। Google Cloud-এ নতুন SHA-1-এর OAuth client যোগ করুন, পুরোনোটি মুছুন। |
| 13 | Keystore/পাসওয়ার্ড ফাঁস হয়েছে সন্দেহ | উপরের ১২-এর মতো নতুন key-তে যান; পুরোনো SHA-1-এর OAuth client মুছুন; পুরোনো build ফোন থেকে সরান। |
| 14 | ফোনের সব তথ্য মোছা দরকার (ফোন বিক্রি) | সেটিংস → গোপনীয়তা ও তথ্য → সংযোগ বিচ্ছিন্ন করুন → "এই ফোন থেকে সব তথ্য মুছুন" → তারপর uninstall। |

## রিস্টোরের পর যাচাই
১. ইনবক্স/খুঁজুন-এ আইটেম সংখ্যা মেলান। ২. কয়েকটি আইটেমের ফাইল খুলে দেখুন। ৩. সেটিংস → আমার ডাটা এক্সপোর্ট → "যাচাই" চালান।
৪. Notion সিঙ্ক চালু করে নিশ্চিত হন নতুন ডুপ্লিকেট পেজ হচ্ছে না।

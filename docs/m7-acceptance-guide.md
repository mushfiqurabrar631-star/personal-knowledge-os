# M7 — ফোনে Acceptance পরীক্ষার গাইড (স্পেক §13.2)

এই পরীক্ষাগুলো শুধু আপনার আসল Android ফোনে, আপনার Notion token, Google অ্যাকাউন্ট ও Gemini key দিয়ে করা যায়।
অটোমেটেড টেস্ট আগেই পাস করেছে, কিন্তু নিচের কোনোটি **এখনো করা হয়নি** — তাই সবগুলো এখন *Pending*।
প্রতিটি শেষ করে শেষের টেবিলে ✅/❌ লিখুন। কোনো ধাপ ব্যর্থ হলে স্ক্রিনশট রাখুন।

**শুরুর প্রস্তুতি**
1. GitHub → Actions → সর্বশেষ সফল run → `pkos-<নম্বর>-debug-apk` ডাউনলোড করে ফোনে install করুন
   (অথবা নিজের কম্পিউটারে `./gradlew :app:assembleDebug`)। অ্যাপের নাম *PKOS (debug)*, version `0.7.0-m7-debug`।
2. পুরোনো (২১ নভেম্বরের আগের) debug build থাকলে আগে uninstall করুন (দেখুন `security-debug-keystore-history.md`)।
3. Settings → গোপনীয়তা ও তথ্য খুলে রাখুন — প্রতিটি ক্লাউড পরীক্ষার পরে এখানে কী পাঠানো হলো দেখা যাবে।

---

### ক. Capture (সংগ্রহ)
**1. সাধারণ লেখা share** — যেকোনো notes অ্যাপে একটু লেখা select → Share → PKOS।
✔ পাস: "সেভ হয়েছে" দেখায়; Inbox-এ লেখাসহ আইটেম আসে।

**2. Chrome URL** — Chrome-এ কোনো লেখা খুলুন → ⋮ → Share → PKOS।
✔ পাস: আইটেমে URL আছে, প্ল্যাটফর্ম Website/Article।

**3. YouTube URL** — YouTube অ্যাপে ভিডিও → Share → PKOS।
✔ পাস: ভিডিও লিংক সেভ, প্ল্যাটফর্ম YouTube।

**4. Facebook share** — Facebook পোস্ট → Share → Copy/Share to app → PKOS।
✔ পাস: যা এসেছে (লিংক/লেখা) সেভ হয়; কিছু না এলে অ্যাপ ক্র্যাশ না করে বোঝায়।

**5. Gallery ছবি + OCR** — Gallery-তে লেখাসহ একটি স্ক্রিনশট → Share → PKOS। কিছুক্ষণ পর আইটেম খুলুন।
✔ পাস: ছবি সংযুক্ত; লেখা চিনতে পারলে আইটেমের লেখায় আসে; না পারলে ছবিটা অন্তত থাকে, ক্র্যাশ নেই।

**6. PDF** — Files অ্যাপে একটি PDF → Share → PKOS।
✔ পাস: PDF সংযুক্ত; লেখা থাকলে তা বের করে সাজানো হয়।

**7. Floating বাটন** — Settings → Floating capture চালু → অনুমতি দিন → অন্য অ্যাপে গিয়ে ভাসমান বাটনে চাপুন → নোট লিখে সেভ। তারপর সুইচ বন্ধ করুন।
✔ পাস: অনুমতি চাওয়া হয় শুধু চালু করলে; সেভ হয়; বন্ধ করলে বাটন চলে যায়।

### খ. অফলাইন ও স্থায়িত্ব
**8. Airplane mode-এ capture** — Airplane mode চালু → ২–৩টি লিংক share করুন → Inbox দেখুন → Airplane mode বন্ধ করুন।
✔ পাস: অফলাইনেও সঙ্গে সঙ্গে সেভ; নেট ফিরলে নিজে থেকেই সাজানো/সিঙ্ক শুরু।

**9. Force-stop / reboot** — Airplane mode-এ ১টি আইটেম সেভ → Settings → Apps → PKOS → Force stop → ফোন restart → নেট চালু।
✔ পাস: আইটেম আছে; অপেক্ষমাণ কাজ পরে নিজে থেকেই শেষ হয়।

### গ. Notion (আপনার token লাগবে — token শুধু অ্যাপের ভেতরে লিখবেন)
**10. পুরোনো properties অক্ষত** — Notion সেটিংসে token দিন → "সেভ ও যাচাই" → সিঙ্ক চালু → ১টি আইটেম সিঙ্ক হতে দিন।
✔ পাস: Master Database-এর কোনো column/option বদলায়নি; পুরোনো ১৫টি এন্ট্রি অপরিবর্তিত; নতুন পেজে শুধু অনুমোদিত ঘরগুলো ভরা।

**11. একই Capture ID দুবার পেজ বানায় না** — সিঙ্কের মাঝখানে Airplane mode চালু/বন্ধ করুন, তারপর "এখন সিঙ্ক"।
✔ পাস: Notion-এ ওই আইটেমের একটাই পেজ।

**12. 429 / অনুমতি ব্যর্থতা** — Notion-এ integration থেকে Master Database-এর connection সরিয়ে দিন → নতুন আইটেম সেভ করুন।
✔ পাস: অ্যাপে "অনুমতি দরকার" দেখায়; ফোনের আইটেম অক্ষত। Connection ফিরিয়ে দিলে সিঙ্ক হয়।

### ঘ. Google Drive ব্যাকআপ (আপনার Google অ্যাকাউন্ট লাগবে)
**13. এনক্রিপ্টেড ব্যাকআপ** — Backup → Drive সংযোগ → রিকভারি কী তৈরি করে কাগজে লিখে রাখুন → "এখনই ব্যাকআপ"।
✔ পাস: "যাচাইসহ সম্পন্ন"; Drive-এ "Personal Knowledge OS Backups" ফোল্ডারে ফাইল আছে; ফাইলটি খুললে পড়া যায় না (এনক্রিপ্টেড)।

**14. নতুন install-এ restore** — অ্যাপ uninstall → আবার install → Backup → Drive সংযোগ → রিকভারি কী দিন → restore preview দেখে নিশ্চিত করুন।
✔ পাস: সব আইটেম, ট্যাগ, টপিক ফিরে আসে; Notion-এ নতুন করে পেজ তৈরি হয় না।

**15. ফাইলের hash মেলে** — restore-এর পর ছবি/PDF-সহ আইটেম খুলুন; Export → "এখন যাচাই করুন"।
✔ পাস: "সব ঠিক আছে … SHA-256 মিলেছে"।

### ঙ. AI ও গোপনীয়তা
**16. Cloud AI বন্ধ থাকলে কিছু যায় না** — Settings → Cloud AI বন্ধ → ২টি আইটেম সেভ → গোপনীয়তা ও তথ্য → সাম্প্রতিক ক্লাউড প্রসেসিং।
✔ পাস: নতুন কোনো সারি নেই।

**17. কম নিশ্চয়তা → Needs Review** — অস্পষ্ট একটি লেখা সেভ করুন (যেমন "abc 123")।
✔ পাস: আইটেম "রিভিউ দরকার"-এ যায়, নিজে কোনো টপিক বানায় না।

**18. আপনার এডিট AI মুছে দেয় না** — Airplane mode চালু → একটি লিংক সেভ → সঙ্গে সঙ্গে আইটেম খুলে ✏️ দিয়ে শিরোনাম বদলান → Airplane mode বন্ধ করে সাজানো শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
✔ পাস: আপনার শিরোনাম থেকে যায়।

**19. অফলাইনে খোঁজ** — Airplane mode → Search-এ কয়েকটি শব্দ, একটি বাংলা প্রতিশব্দ (যেমন "টাকা") ও একটি ভুল বানান।
✔ পাস: ফল আসে, কেন মিলেছে তা দেখায়।

**20. Ask উৎস দেখায়, বানিয়ে বলে না** — Ask-এ এমন প্রশ্ন যা আপনার সেভে আছে, আর এমন একটি যা নেই।
✔ পাস: প্রথমটিতে [১] উৎসসহ উত্তর, উৎসে চাপলে আইটেম খোলে; দ্বিতীয়টিতে "আপনার সেভে উত্তর পাওয়া যায়নি"।

**21. Gemini (আপনার free key)** — AI সেটিংসে key দিন → Cloud AI চালু → "অর্থ দিয়ে খোঁজ" চালু → ২–৩টি নতুন আইটেম সেভ করে অপেক্ষা করুন → এমন প্রতিশব্দে খুঁজুন যা লেখায় নেই → Ask-এ প্রশ্ন করুন → একটি আইটেম "শুধু এই ফোনে রাখুন" করে তার বিষয়ে প্রশ্ন করুন।
✔ পাস: "অর্থে মিল" ব্যাজ; "AI উত্তর · আপনার আইটেম থেকে" উৎসসহ; "শুধু ফোনে" আইটেম উত্তরে আসে না, "১টি… পাঠানো হয়নি" দেখায়; গোপনীয়তা পাতায় প্রতিটি পাঠানো আইটেম তালিকাভুক্ত, local-only টি নেই।

### চ. Export ও Privacy controls
**22. Export (ফাইল বেছে নেওয়ার পাতা)** — Export → "শুধু ফোনে" বন্ধ রেখে "এক্সপোর্ট ফাইল তৈরি" → Downloads-এ সেভ। আবার "শুধু ফোনে" চালু করুন → পাসওয়ার্ড দুবার দিন → সেভ।
✔ পাস: প্রথম ZIP-এ `pkos-export.json`, `items.csv`, `markdown/`, `attachments/`, `integrity-report.json`; CSV-তে বাংলা ঠিকঠাক; দ্বিতীয় ZIP 7-Zip/ZArchiver-এ পাসওয়ার্ড ছাড়া খোলে না, পাসওয়ার্ডে খোলে। ফাইল বাছাই বাতিল করলে কিছু লেখা হয় না।

**23. AI ইতিহাস ও ক্যাশ** — গোপনীয়তা ও তথ্য → "AI ইতিহাস মুছুন" → নিশ্চিত; তারপর "ক্যাশ মুছুন"।
✔ পাস: ক্লাউড-কার্যক্রমের তালিকা খালি; সব আইটেম, ফাইল, সেটিং যেমন ছিল।

**24. Notion বিচ্ছিন্ন** — Notion সেটিংস → "Notion থেকে বিচ্ছিন্ন করুন"।
✔ পাস: সিঙ্ক বন্ধ, token নেই; Notion-এর পেজ আছে। (পুরো বাতিল: notion.so → Settings → Connections থেকে integration সরান।)

**25. Drive বিচ্ছিন্ন + অনুমতি বাতিল** — Backup → "Drive সংযোগ বন্ধ করুন"।
✔ পাস: "Google অনুমতি বাতিল হয়েছে"; myaccount.google.com/permissions-এ PKOS আর নেই; Drive-এর পুরোনো ব্যাকআপ আছে।

**26. সব তথ্য মুছুন (সবার শেষে, ব্যাকআপ নেওয়ার পরে!)** — প্রথমে #13 অনুযায়ী ব্যাকআপ ও রিকভারি কী নিশ্চিত করুন → গোপনীয়তা ও তথ্য → "সব তথ্য মুছুন" → নির্দেশিত শব্দ লিখুন → নিশ্চিত।
✔ পাস: ভুল শব্দে বোতাম বন্ধ থাকে; মোছার পর অ্যাপ শুরুর পর্দায় (onboarding) যায়; Notion পেজ ও Drive ব্যাকআপ থাকে; #14-এর মতো restore করলে সব ফিরে আসে।

### ছ. রিমাইন্ডার, Accessibility, Performance
**27. রিমাইন্ডার** — Settings → রিমাইন্ডার চালু → Android 13+-এ নোটিফিকেশন অনুমতি দিন।
✔ এখনই পাস করা যায়: নতুন install-এ বন্ধ থাকে; অনুমতি শুধু চালু করলে চাওয়া হয়। আসল নোটিফিকেশন: পিন/গুরুত্বপূর্ণ কোনো আইটেম ৩০ দিন না খোলা থাকলে দিনে একবার একটি নীরব নোটিফিকেশন — তাই এ অংশ ৩০ দিন পরে দেখা যাবে।

**28. TalkBack** — Settings → Accessibility → TalkBack চালু → Home, Inbox, একটি আইটেম, Settings, গোপনীয়তা পাতা ঘুরে দেখুন।
✔ পাস: প্রতিটি বোতাম/সুইচের নাম পড়ে; কোনো বোতাম "unlabeled" নয়।

**29. বড় ফন্ট** — Settings → Display → Font size সর্বোচ্চ।
✔ পাস: লেখা কাটা পড়ে না, বোতাম চাপা যায়।

**30. গতি ও ব্যাটারি** — অ্যাপ বন্ধ করে খুলুন (৩ বার), কত সময় লাগে আন্দাজ করুন; একদিন ব্যবহারের পর Settings → Battery → PKOS-এর ব্যবহার।
✔ পাস: খুলতে ~২ সেকেন্ডের কম; ব্যাটারি ব্যবহার সামান্য; খোঁজ টাইপ করার সাথে সাথে ফল।
